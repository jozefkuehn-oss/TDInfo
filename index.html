Why this setup exists

Running a modern broadcast/IMAG production means the same camera and content feeds need to go multiple places at once. Rather than wiring each source directly to each destination, this system uses a routing hub as a central patch bay and a switcher to do all the creative decision-making — cuts, keys, transitions — before sending finished feeds back out to wherever they need to go.
